# 🇳🇴 Norsk

## Bidragsguide

- Formatér koden med prettier før du committer: `npx prettier --write .`
- Sørg for at `npm run build` går gjennom uten feil. Begge deler sjekkes automatisk ved hver push.

# 🇬🇧 English

## Contribution guidelines

- Format your code with prettier before committing: `npx prettier --write .`
- Make sure `npm run build` passes without errors. Both are checked automatically on every push.
